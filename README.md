# İzometrik Bursa: dokuz çizim denemesi

Ulu Cami çevresindeki Zindan–Yeşil 3B modelinden alınan dokuz çekimin yapay zekâ ile çizim tarzına dönüştürülmüş, deneysel önizlemesi. `index.html` doğrudan açılabilir; GitHub Pages altında statik olarak çalışır.

Çizimler birbirinden bağımsız üretilmiştir. Kenarlarda kaymalar, değişen yapı ayrıntıları ve model kapsamı dışındaki boş alanlar görülebilir; bunlar doğrulanmış konumsal harita veya ölçüm verisi değildir. Merkez çekimde karoların yüklenmesi süre sınırında tamamlanmamıştır. Kaynak model veya hakları bu depoda dağıtılmaz; görsellerin kullanım izinleri ayrıca değerlendirilmelidir.

Fareyle sürükleme ve tekerlekle yakınlaşma, dokunmatik ekranda sürükleme ve iki parmakla yakınlaşma desteklenir. Çerçeve düğmesi karo sınırlarını açar ve kapatır.
